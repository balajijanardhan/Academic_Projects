Housing Price Prediction¶

Introduction: Housing Price Prediction is all about using smart computer programs to guess how much a house might cost in the future. This is super important because it helps people decide when to buy or sell a house, figure out the right price, and find good investment opportunities.¶

Business Question: How can real estate agents predict the selling price of a house based on its various features and characteristics, such as area, number of bedrooms, bathrooms, and other attributes?¶

Expected Benefit : It helps in decision making while purchasing the house.¶

This project benefits for real estate agents, common man and anyone who is planning to purchase a house by doing some analysis.¶

Project Dataset¶

Dataset Description (Source : Kaggle)

Price: The price of the house.

Area: The total area of the house in square feet.

Bedrooms: The number of bedrooms in the house.

Bathrooms: The number of bathrooms in the house.

Stories: The number of stories in the house.

Mainroad: Whether the house is connected to the main road (Yes/No).

Guestroom: Whether the house has a guest room (Yes/No).

Basement: Whether the house has a basement (Yes/No).

Hot water heating: Whether the house has a hot water heating system (Yes/No).

Airconditioning: Whether the house has an air conditioning system (Yes/No).

Parking: The number of parking spaces available within the house.

Prefarea: Whether the house is located in a preferred area (Yes/No).

Furnishing status: The furnishing status of the house (Fully Furnished, Semi-Furnished, Unfurnished).

# Step 1: Improve the Normality of the Data (Log-Transform Skewed Numeric Data)

# Log-transform positively skewed numeric data
skewed_vars = df.select_dtypes(include=['int64', 'float64']).apply(lambda x: stats.skew(x))
skewed_vars = skewed_vars[abs(skewed_vars) > 0.5]  # Adjust the skewness threshold as needed

for var in skewed_vars.index:
    if (var != 'price') and (min(df[var]) > 0):
        df[var] = np.log1p(df[var])

# Step 2: Reduce Multicollinearity (Remove Highly Correlated Variables)

# Calculate and visualize the correlation matrix
corr_matrix = df.corr()

# Identify highly correlated variables (e.g., correlation > 0.7)
highly_correlated = set()
for i in range(len(corr_matrix.columns)):
    for j in range(i):
        if abs(corr_matrix.iloc[i, j]) > 0.7:
            colname = corr_matrix.columns[i]
            highly_correlated.add(colname)

# Remove highly correlated variables
df_cleaned = df.drop(columns=highly_correlated)

# Rebuild the linear model with the cleaned data
X_cleaned = df_cleaned.drop('price', axis=1)
y_cleaned = df_cleaned['price']

X_cleaned = sm.add_constant(X_cleaned)
model_cleaned = sm.OLS(y_cleaned, X_cleaned).fit()

# Get the summary of the cleaned model
